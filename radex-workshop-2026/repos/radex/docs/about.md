# About

radex is co-developed by [HPE](https://hpe.com) and [RADICAL Cybertools](https://radical-cybertools.github.io) team as a data exchange layer used by other RCT projects (such as [RHAPSODY](https://radical-cybertools.github.io/rhapsody)) to move data between heterogeneous simulation, AI, and orchestration components in-memory over interconnects.
