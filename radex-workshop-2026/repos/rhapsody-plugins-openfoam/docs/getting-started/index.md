# Getting Started

Welcome to the RHAPSODY OpenFOAM plugin! This section will guide you from installation to running your first OpenFOAM case as a RHAPSODY workflow.

## Learning Path

1.  **[Installation](installation.md)**: Install the Python plugin and its dependencies (RHAPSODY, Dragon, and radex).
2.  **[Building the OpenFOAM Function Objects](building-the-function-object.md)**: Compile the `radexWrite` and `radexRead` function objects against your OpenFOAM installation.
3.  **[Quick Start](quick-start.md)**: Define and run a simple OpenFOAM case as a staged RHAPSODY workflow.

!!! note "Prerequisites"
    An existing, activated OpenFOAM installation is required. The Python plugin also depends on [RHAPSODY](https://radical-cybertools.github.io/rhapsody) and [Dragon](https://dragonhpc.github.io/dragon/doc/_build/html/index.html) for task execution, and the `radexWrite`/`radexRead` function objects depend on [radex](https://github.com/radical-cybertools/radex).

## Next Steps

Once you've mastered the basics, explore the [Examples](../examples/index.md) or the full **[API Reference](../api/index.md)** for detailed module and class documentation.
