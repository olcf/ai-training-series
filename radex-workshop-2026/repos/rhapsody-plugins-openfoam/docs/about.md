# About

`rhapsody-plugins-openfoam` is developed by the [RADICAL Cybertools](https://radical-cybertools.github.io) team to connect [OpenFOAM](https://www.openfoam.com) CFD workflows to [RHAPSODY](https://radical-cybertools.github.io/rhapsody), the runtime system for heterogeneous HPC-AI workloads, and [radex](https://github.com/radical-cybertools/radex), the in-memory data exchange layer used to stream field data out of a running solver.
